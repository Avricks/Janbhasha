# Contributing to Janbhasha

Thank you for your interest in contributing to Janbhasha! This document provides guidelines and instructions for contributing.

## Code of Conduct

We are committed to providing a welcoming and inclusive environment for all contributors. Please be respectful and constructive in all interactions.

## How to Contribute

### Reporting Issues

- Use the issue tracker to report bugs or request features
- Provide clear, detailed descriptions of the issue
- Include steps to reproduce bugs and expected vs actual behavior
- Attach relevant logs, screenshots, or error messages

### Submitting Pull Requests

1. Fork the repository and create a feature branch
2. Make your changes, following the code style guidelines
3. Write or update tests as necessary
4. Submit a pull request with a clear description of changes
5. Respond to review feedback promptly

## Development Setup

Refer to the [README.md](README.md) for installation and development setup instructions.

## Code Style

- Follow language-specific conventions (ESLint for JS/TS, Black for Python)
- Use meaningful variable and function names
- Add comments for complex logic
- Maintain consistent indentation and formatting

## Testing

- Write unit tests for new features
- Ensure all tests pass before submitting PR
- Add integration tests for service interactions
- Include E2E tests for user flows

## Documentation

- Update README and relevant docs for new features
- Document API endpoints and their parameters
- Add inline comments for complex algorithms
- Keep the `.ai/` documentation updated for AI/agent changes

## Commit Messages

Use clear, descriptive commit messages:
```
feature: Add speech recognition for Santhali
fix: Resolve translation sync issue
docs: Update API documentation
```
