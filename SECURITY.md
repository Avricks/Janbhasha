# Security Policy

## Reporting Security Vulnerabilities

If you discover a security vulnerability in Janbhasha, please email security@janbhasha.dev instead of using the public issue tracker.

**Do not** disclose security vulnerabilities publicly before they have been addressed.

### Reporting Process

1. Email security details to security@janbhasha.dev
2. Include steps to reproduce, if possible
3. Allow reasonable time for a response and fix
4. Coordinate disclosure timing with the team

## Security Practices

### Data Protection

- All user data is encrypted in transit (TLS 1.3+)
- Sensitive data is encrypted at rest
- Personal information is handled according to applicable privacy regulations

### Authentication & Authorization

- Secure authentication mechanisms for all services
- Role-based access control (RBAC) implemented
- Regular security audits of permission systems

### Dependency Management

- Regular updates of dependencies
- Security scanning for known vulnerabilities
- Automated dependency updates via Dependabot

### Code Review

- All code changes go through peer review
- Security-focused code reviews for critical paths
- Automated security scanning in CI/CD pipeline

## Compliance

- GDPR compliance for personal data
- COPPA compliance for child user data
- Regular security assessments and penetration testing

## Incident Response

In case of a security incident:
1. Affected users will be notified promptly
2. Incident details will be disclosed transparently
3. Corrective measures will be implemented and documented

## Questions?

For security-related questions, contact: security@janbhasha.dev
