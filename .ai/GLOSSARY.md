# Janbhasha Glossary

## Learning & Education

- **Adaptive Learning**: Personalized learning paths that adjust based on learner performance
- **Assessment**: Evaluation of learner knowledge and skills through quizzes, exercises
- **Curriculum**: Structured outline of language learning content and progression
- **Pedagogy**: Science and art of teaching methods and educational principles
- **Skill Level**: Classification of language proficiency (beginner, intermediate, advanced)

## Language & Linguistics

- **Morphology**: Study of word structure and formation
- **Phonetics**: Study of speech sounds and their production
- **Phonology**: Study of sound systems in language
- **Semantics**: Study of meaning in language
- **Syntax**: Study of sentence structure and word order
- **Orthography**: Writing system and spelling conventions

## Santhali Language

- **Ol Chiki Script**: Native script for Santhali (74 characters)
- **Santhali Speakers**: ~7.5 million native speakers (mostly in India)
- **Santhali Dialects**: Regional variations across Jharkhand, Odisha, West Bengal

## Mundari Language

- **Warang Citi Script**: Native script for Mundari
- **Mundari Speakers**: ~1.5 million native speakers
- **Mundari Regions**: Chota Nagpur plateau region

## Ho Language

- **Ho Script**: Modified Devanagari and Latin script options
- **Ho Speakers**: ~700,000 native speakers
- **Ho Regions**: Jharkhand and surrounding areas

## Technology & Architecture

- **API**: Application Programming Interface for service communication
- **Cache**: Fast storage layer for frequently accessed data
- **Microservice**: Small, independently deployable service
- **Offline-First**: Design approach prioritizing offline functionality
- **Sync**: Synchronization of data across devices
- **Vector Database**: Database optimized for embeddings and semantic search

## AI & Machine Learning

- **Embedding**: Numerical representation of words or concepts
- **Fine-tuning**: Adapting pre-trained models for specific tasks
- **Inference**: Using trained model to make predictions
- **Language Model**: AI model trained on language data
- **Quantization**: Reducing model size for efficiency
- **Transformer**: Deep learning architecture for NLP tasks

## Speech

- **ASR**: Automatic Speech Recognition (speech-to-text)
- **TTS**: Text-to-Speech (speech synthesis)
- **Prosody**: Intonation, stress, and rhythm in speech
- **Accent**: Characteristic pronunciation pattern

## Data & Synchronization

- **Conflict Resolution**: Strategy for merging conflicting changes
- **Data Consistency**: Ensuring all copies of data are identical
- **Eventually Consistent**: Data becomes consistent over time
- **Merge Strategy**: Algorithm for combining changes
- **Replica**: Copy of data maintained locally

## User Types

- **Learner**: Student using the platform to learn a language
- **Educator**: Teacher/instructor creating and managing content
- **Administrator**: System operator managing infrastructure
- **Content Creator**: Linguist or expert creating language content

## Metrics & Analytics

- **Engagement Rate**: Frequency and depth of platform usage
- **Retention Rate**: Percentage of users continuing after initial period
- **Learning Outcome**: Measurable improvement in language skills
- **Completion Rate**: Percentage of learners finishing courses
- **Performance Metric**: Quantifiable measure of system or learner performance
