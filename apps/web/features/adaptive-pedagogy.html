The 3-Parameter Logistic Psychometric Model

Standard linear school testing penalizes tribal first-generation learners unfairly. Janbhasha evaluates student literacy using a calibrated 3-Parameter Logistic (3PL) Item Characteristic Curve:

P(θ) = c + (1 - c) / [1 + exp(-a · (θ - b))]
  1. STAGE 01

    Item Discrimination Calibration (a)

    Measures how effectively a specific Ol Chiki phoneme or grammar question differentiates between high and low ability learners.

  2. STAGE 02

    Difficulty Standardization (b)

    Indexes the exact point on the ability continuum (θ) where a child has a 50% probability of mastering the script exercise.

  3. STAGE 03

    Pseudo-Guessing Floor (c)

    Accounts for random choice selection in multiple-choice formats, preventing artificial deflation of learner competency.

  4. STAGE 04

    Real-Time Ability Update (θ)

    Bayesian Maximum A Posteriori updates child capability parameter (θ) after every response without lag.
