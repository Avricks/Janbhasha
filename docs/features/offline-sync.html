Offline Delta Synchronization Architecture

A resilient edge storage and distributed ledger engine engineered to provide uninterrupted literacy learning in remote tribal villages with intermittent or zero internet connectivity.

Conflict-Free Edge Synchronization Ledger

Unlike cloud-tethered applications that stall upon disconnection, Janbhasha treats connectivity as an occasional luxury. All state transitions, item responses, and audio logs commit to an encrypted local SQLite database.

  1. STAGE 01

    Local Ledger Commit

    Every student question attempt, audio repetition, and lesson milestone commits to Room SQLite within 12 milliseconds using write-ahead logging (WAL).

  2. STAGE 02

    Vector Clock Timestamping

    Transactions receive logical causality vectors [Node_ID, Sequence_Num] preventing causal inversion across multi-tablet village classroom deployments.

  3. STAGE 03

    Bandwidth-Constrained Batching

    Upon detecting cellular heartbeat (2G/EDGE/4G), pending deltas are compressed with Brotli into micro-payloads under 5 KB per student session.

  4. STAGE 04

    CRDT Conflict Resolution

    Concurrent student record modifications merge deterministically into the master partition without requiring manual teacher intervention.
