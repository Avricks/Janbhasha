# Santhali Language & Script Linguistic Documentation

## 1. Overview
Santhali belongs to the North Munda group of the Austroasiatic language family. It is recognized under the Eighth Schedule of the Indian Constitution.

## 2. Ol Chiki Script
Invented in 1925 by Pandit Raghunath Murmu, Ol Chiki is an alphabetic script containing:
- 30 primary characters (6 vowels and 24 consonants).
- Diacritics modifying length, nasalization, and glottal tone.

## 3. Unicode Range
`U+1C50` to `U+1C7F` (Ol Chiki Unicode Block).
