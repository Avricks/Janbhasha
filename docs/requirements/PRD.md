# Janbhasha Product Requirements Document (PRD)

## 1. Executive Summary
Janbhasha is an AI-powered vernacular pedagogy and literacy acceleration platform tailored for indigenous communities in Jharkhand and eastern India. It focuses on Santhali (Ol Chiki script), Mundari (Warang Citi script), and Ho (Warang Citi / Devanagari).

## 2. Key Target Audience
- Primary school children and early learners in tribal regions.
- Government and tribal school educators (DIKSHA / SWAYAM framework).
- District administrators and linguists preserving endangered scripts.

## 3. Core Functional Pillars
- **Offline-First Synchronization**: Local SQLite / AsyncStorage caching with asynchronous delta sync.
- **Accessible UI/UX**: Strict WCAG 2.1 AA compliance (48px+ touch targets, 4.5:1 contrast, high-contrast mode, dark mode).
- **Adaptive Pedagogy**: Item Response Theory (IRT 3PL) ability estimation for personalized question sequencing.
- **Multimodal Vernacular AI**: Localized Speech-to-Text, Text-to-Speech, and Machine Translation models.
